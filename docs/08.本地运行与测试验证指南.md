## 二、编译与构建（已验证）

### 2.1 坑①：Gradle 插件下载失败

直接运行 `./gradlew compileJava` 会报错：

```
Could not resolve com.netflix.nebula:nebula-oss-publishing-plugin:3.6.0
The server may not support the client's requested TLS protocol versions
```

**原因**：国内网络访问 plugins.gradle.org 不稳定。

**解决**：创建阿里云镜像 init 脚本（不修改仓库任何文件）：

```bash
cat > /tmp/eureka-init.gradle << 'SCRIPT'
settingsEvaluated { settings ->
    settings.pluginManagement {
        repositories {
            maven { url 'https://maven.aliyun.com/repository/gradle-plugin' }
            maven { url 'https://maven.aliyun.com/repository/public' }
            gradlePluginPortal()
        }
    }
}
allprojects {
    repositories {
        maven { url 'https://maven.aliyun.com/repository/public' }
        maven { url 'https://maven.aliyun.com/repository/central' }
        mavenCentral()
    }
}
SCRIPT
```

### 2.2 编译命令（实测 BUILD SUCCESSFUL）

```bash
# 编译核心模块（首次约 55s，含依赖下载）
./gradlew -I /tmp/eureka-init.gradle :eureka-core:compileJava :eureka-client:compileJava

# 构建可部署的 war 包（实测 6s，产物 22MB）

# 产物：eureka-server/build/libs/eureka-server-0.0.1-SNAPSHOT.war
```

## 三、运行真实的 Eureka Server（已验证）

### 3.1 推荐方式：通过集成测试启动

仓库自带的端到端集成测试 `EurekaClientServerRestIntegrationTest` 会：
1. 用 Jetty 加载真实的 eureka-server war（`new Server(8080)` + `WebAppContext`）
2. 创建真实的 HTTP 客户端（Jersey）
3. 跑完整的注册→心跳→下线→批量复制流程

```bash
./gradlew -I /tmp/eureka-init.gradle :eureka-server:test \
  --tests "com.netflix.eureka.resources.EurekaClientServerRestIntegrationTest"
```

### 3.2 坑②：8080 端口被占用

测试硬编码 8080 端口（EurekaClientServerRestIntegrationTest.java:237），本机被占用时报：

```
EurekaClientServerRestIntegrationTest > classMethod FAILED
    java.net.BindException at EurekaClientServerRestIntegrationTest.java:244
```

**解决**：临时把测试中的 8080 改为空闲端口（如 18080），跑完再还原：

```bash
# 修改（macOS sed）
sed -i '' 's/:8080/:18080/g; s/Server(8080)/Server(18080)/; s/"8080"/"18080"/' \
  eureka-server/src/test/java/com/netflix/eureka/resources/EurekaClientServerRestIntegrationTest.java
# 跑测试 ...
# 还原
sed -i '' 's/:18080/:8080/g; s/Server(18080)/Server(8080)/; s/"18080"/"8080"/' \
  eureka-server/src/test/java/com/netflix/eureka/resources/EurekaClientServerRestIntegrationTest.java
```

### 3.4 备选方式：独立部署 war

如果想要长期运行的 Server（而不是测试中临时启动），将 war 部署到任意 Servlet 容器：

```bash
# 方式A：Tomcat
cp eureka-server/build/libs/eureka-server-*.war $TOMCAT_HOME/webapps/eureka.war
# 访问 http://localhost:8080/eureka

# 方式B：jetty-runner（需自行下载 jetty-runner.jar）
java -jar jetty-runner.jar --port 8080 eureka-server/build/libs/eureka-server-*.war
```

注意：单机启动会经历 **5 分钟启动保护期**（syncUp 为空），期间查询接口返回 403。
测试环境可加 JVM 参数跳过：`-Deureka.waitTimeInMsWhenSyncEmpty=0`（详见文档 05）。
