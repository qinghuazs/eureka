## 二、实例完整生命周期时序（一个实例从生到死）

```mermaid
sequenceDiagram
    autonumber
    participant P as 服务实例进程
    participant C as DiscoveryClient<br/>(实例内)
    participant S as Eureka Server A
    participant S2 as Eureka Server B
    participant Q as 消费方客户端

    Note over P,Q: ════ 阶段1:启动与注册(文档01) ════
    P->>C: 进程启动,创建DiscoveryClient
    C->>C: 启动三大定时任务<br/>(心跳/拉取/信息同步)
    Note over C: 等待40s(首次注册延迟)
    C->>S: POST 注册(InstanceInfo)
    S->>S: 写入双层Map注册表<br/>状态规则链裁决<br/>失效缓存,进增量队列
    S-->>C: 204
    S->>S2: 异步批量复制注册

    Note over P,Q: ════ 阶段2:被发现(文档03) ════
    Q->>S: GET /v2/apps/delta (增量拉取)
    S->>S: 读缓存(readOnly→readWrite→注册表)
    S-->>Q: 增量数据(含新实例,ADDED)
    Q->>Q: 合并到本地缓存,hashcode校验
    Note over Q: 业务代码现在能发现该实例了<br/>(注册→可见延迟最长约90s)

    Note over P,Q: ════ 阶段3:存活期(文档02) ════
    loop 每30s
        C->>S: PUT 心跳(带lastDirtyTimestamp)
        S->>S: 更新租约时间戳<br/>续约统计+1(自我保护数据)
        S-->>C: 200
        S->>S2: 异步复制心跳<br/>(404→补注册/409→拉数据,集群对账)
    end

    Note over P,Q: ════ 阶段4a:优雅下线(文档04) ════
    P->>C: kill -15 / @PreDestroy
    C->>C: 停定时任务→标DOWN
    C->>S: DELETE 下线
    S->>S: 移除租约,DELETED进增量队列
    S->>S2: 复制下线

    Note over P,Q: ════ 阶段4b:意外死亡(文档04) ════
    Note over P: 进程崩溃,心跳停止
    Note over S: 等待租约过期(180s)
    loop 每60s EvictionTask
        S->>S: 自我保护检查
        alt 集群续约数正常
            S->>S: 随机分批剔除过期实例<br/>(单轮≤15%,不复制给S2)
        else 续约数<85%阈值
            Note over S: 自我保护!跳过剔除
        end
    end

    Note over P,Q: ════ 阶段5:消失被感知(文档03) ════
    Q->>S: 增量拉取
    S-->>Q: DELETED记录
    Q->>Q: 从本地缓存删除该实例
```

## 五、关键时间链（回答"要多久"类问题）

```
新实例注册 → 消费方可调用:
  注册写入(0) → 读写缓存失效(0) → 只读缓存同步(≤30s) → 消费方拉取(≤30s) → Ribbon缓存(≤30s)
  = 最坏约 90s

实例正常下线 → 消费方不再调用:
  DELETE下线(0) → 缓存失效+增量队列(0) → 只读缓存(≤30s) → 消费方拉取(≤30s) → Ribbon(≤30s)
  = 最坏约 90s

实例意外死亡 → 消费方不再调用:
  最后心跳(0) → 租约过期(180s,因bug是2倍) → 剔除任务(≤60s) → 缓存链(≤90s)
  = 最坏约 5.5 分钟  ← 这是Eureka最大的短板

集群节点A收到注册 → 节点B可见:
  本地写入(0) → 批处理攒批(≤500ms) → HTTP复制(网络) → B写入(0)
  = 正常 <1s; 复制失败时靠下次心跳复制修复(≤30s)
```
